# Pertemuan 4 — Praktikum Flutter

## Deskripsi
Pertemuan 4 berisi kegiatan praktikum pengembangan aplikasi mobile menggunakan Flutter dan bahasa pemrograman Dart. Praktikum ini bertujuan untuk meningkatkan pemahaman dalam menyusun kode program dan mengembangkan antarmuka aplikasi.

## Tujuan
- Memahami penerapan widget pada Flutter.
- Melatih kemampuan menulis kode menggunakan Dart.
- Mengembangkan tampilan aplikasi sesuai instruksi praktikum.
- Menjalankan dan menguji aplikasi melalui emulator Android.

## Praktikum
Pada pertemuan ini, mahasiswa mengerjakan latihan praktikum menggunakan Android Studio. Kegiatan meliputi implementasi kode program, penyusunan tampilan aplikasi, serta pengujian untuk memastikan aplikasi dapat dijalankan.

## Teknologi
- Flutter
- Dart
- Android Studio
- Android Emulator

## Cara Menjalankan
1. Buka folder proyek praktikum melalui Android Studio.
2. Buka Terminal pada direktori proyek.
3. Jalankan perintah berikut:

   ```bash
   flutter pub get
   flutter run
   ```

## Kesimpulan
Melalui praktikum ini, mahasiswa berlatih mengembangkan aplikasi mobile menggunakan Flutter, menerapkan widget, serta menguji hasil implementasi program melalui emulator Android.
