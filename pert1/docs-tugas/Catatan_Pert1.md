# Pertemuan 1 — Pengenalan Flutter

## Deskripsi
Pertemuan 1 merupakan tahap awal dalam mempelajari pengembangan aplikasi mobile menggunakan Flutter. Pada pertemuan ini, dilakukan pengenalan struktur dasar aplikasi Flutter serta pembuatan aplikasi sederhana.

## Tujuan
- Mengenal Flutter sebagai framework untuk pengembangan aplikasi mobile.
- Memahami struktur dasar proyek Flutter.
- Mengenal penggunaan widget dalam membangun antarmuka aplikasi.
- Menjalankan aplikasi Flutter pada emulator atau perangkat yang tersedia.

## Praktikum
Pada praktikum ini, dibuat aplikasi sederhana dengan judul **Praktikum 1** dan AppBar bertuliskan **Counter Saya**. Aplikasi juga menampilkan teks sapaan sebagai pengenalan tampilan dasar Flutter.

## Teknologi
- Flutter
- Dart
- Android Studio
- Android Emulator

## Cara Menjalankan
1. Buka folder proyek praktikum melalui Android Studio.
2. Buka Terminal pada direktori proyek.
3. Jalankan perintah berikut:

   ```bash
   flutter pub get
   flutter run
   ```

## Kesimpulan
Melalui praktikum ini, mahasiswa mulai memahami dasar pengembangan aplikasi menggunakan Flutter, mengenal struktur proyek, serta mempelajari cara menampilkan komponen sederhana pada aplikasi mobile.
