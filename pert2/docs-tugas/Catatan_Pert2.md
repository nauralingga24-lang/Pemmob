# Pertemuan 2 — Praktikum Flutter

## Deskripsi
Pertemuan 2 berisi kegiatan praktikum pengembangan aplikasi mobile menggunakan Flutter dan bahasa pemrograman Dart. Pada pertemuan ini, dilakukan pengembangan aplikasi dengan memanfaatkan widget untuk membangun antarmuka pengguna.

## Tujuan
- Memahami penggunaan widget pada Flutter.
- Mempelajari struktur kode aplikasi Flutter.
- Mengembangkan tampilan aplikasi menggunakan widget.
- Menjalankan dan menguji aplikasi melalui emulator Android.

## Praktikum
Pada praktikum ini, mahasiswa membuat dan menjalankan aplikasi Flutter sesuai dengan instruksi praktikum. Pengembangan dilakukan melalui Android Studio dengan memanfaatkan bahasa pemrograman Dart.

## Teknologi
- Flutter
- Dart
- Android Studio
- Android Emulator

## Cara Menjalankan
1. Buka folder proyek `praktikum2` melalui Android Studio.
2. Buka Terminal pada direktori proyek.
3. Jalankan perintah berikut:

   ```bash
   flutter pub get
   flutter run
   ```

## Kesimpulan
Melalui praktikum ini, mahasiswa memperoleh pengalaman dalam mengembangkan aplikasi mobile menggunakan Flutter, memahami struktur kode, serta menjalankan aplikasi pada emulator Android.
