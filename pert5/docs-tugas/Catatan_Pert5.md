# Pertemuan 5 — Penyimpanan Data pada Flutter

## Deskripsi
Pertemuan 5 membahas penerapan penyimpanan data pada aplikasi mobile menggunakan Flutter. Pada praktikum ini, aplikasi dikembangkan dengan memanfaatkan penyimpanan lokal untuk menyimpan dan mengelola data.

## Tujuan
- Memahami konsep penyimpanan data lokal pada Flutter.
- Mengenal penggunaan package untuk menyimpan data.
- Mempelajari cara menyimpan dan mengambil data dari penyimpanan lokal.
- Menerapkan penyimpanan data pada aplikasi mobile.

## Praktikum
Pada pertemuan ini, praktikum menggunakan `shared_preferences` untuk menyimpan data sederhana dan `sqflite` untuk mengelola data menggunakan database SQLite. Package `path` digunakan untuk membantu menentukan lokasi database.

## Teknologi
- Flutter
- Dart
- Android Studio
- `shared_preferences`
- `sqflite`
- `path`
- SQLite

## Cara Menjalankan
1. Buka folder proyek praktikum melalui Android Studio.
2. Buka Terminal pada direktori proyek.
3. Jalankan perintah berikut:

   ```bash
   flutter pub get
   flutter run
   ```

## Kesimpulan
Melalui praktikum ini, mahasiswa mempelajari cara menyimpan dan mengelola data secara lokal pada aplikasi Flutter menggunakan `shared_preferences` dan database SQLite melalui `sqflite`.
