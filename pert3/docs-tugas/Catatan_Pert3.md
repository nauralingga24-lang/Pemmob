# Pertemuan 3 — Praktikum Flutter

## Deskripsi
Pertemuan 3 berisi kegiatan praktikum pengembangan aplikasi mobile menggunakan Flutter dan bahasa pemrograman Dart. Praktikum dilakukan untuk meningkatkan pemahaman dalam membuat antarmuka aplikasi serta menerapkan konsep pemrograman Flutter.

## Tujuan
- Memahami penggunaan widget dalam Flutter.
- Mempelajari penerapan kode Dart pada aplikasi mobile.
- Mengembangkan antarmuka aplikasi sesuai instruksi praktikum.
- Menguji aplikasi menggunakan emulator Android.

## Praktikum
Pada pertemuan ini, mahasiswa mengerjakan praktikum Flutter menggunakan Android Studio. Kegiatan meliputi penulisan kode program, pengembangan tampilan aplikasi, serta menjalankan aplikasi untuk memastikan program dapat berfungsi.

## Teknologi
- Flutter
- Dart
- Android Studio
- Android Emulator

## Cara Menjalankan
1. Buka folder proyek praktikum melalui Android Studio.
2. Buka Terminal pada direktori proyek.
3. Jalankan perintah berikut:

   ```bash
   flutter pub get
   flutter run
   ```

## Kesimpulan
Melalui praktikum ini, mahasiswa memperoleh pengalaman dalam mengembangkan aplikasi mobile menggunakan Flutter, menerapkan widget, serta menguji hasil implementasi program melalui emulator Android.
